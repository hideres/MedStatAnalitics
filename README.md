# МедСтат Аналитика 📊

Курсовая работа Афонин М.А., 2026
Программа на Python для просмотра и анализа медицинской статистики (заболеваемость и смертность) по регионам.

## Что умеет программа:
* Загружать данные из CSV-файлов.
* Строить линейные графики и столбчатые диаграммы.
* Сравнивать графики двух разных регионов на одном экране.
* Строить круговые диаграммы для анализа структуры заболеваний за конкретный год.
* Сохранять готовые графики как картинки (PNG, JPEG).

## 🛠️ Что нужно для работы (зависимости)
Все необходимые библиотеки указаны в файле `requirements.txt`:
* `PyQt6` (для интерфейса)
* `pandas` (для работы с таблицами)
* `matplotlib` и `seaborn` (для рисования графиков)

## 💻 Инструкция по запуску

1. Установите все нужные библиотеки одной командой в терминале:
pip install -r requirements.txt

2. Запустите программу через главный файл main.py

⚠️ Важное примечание
Для работы программы в папке с кодом обязательно должны лежать два файла с данными:
* morbidity.csv (данные по заболеваемости)
* mortality_rate.csv (данные по смертности)
